# Core Concepts

## The Engine
Kinetix uses a semantic understanding engine to parse your natural language into visual structures.

## Diagram Types
We support multiple diagram types:
1. **Flowcharts**: Directed graphs showing process steps.
2. **Sequence Diagrams**: Showing interactions over time.
3. **Mind Maps**: Hierarchical organization of ideas.

## Styling
You can apply global styles to your visuals:
- `sketch`: Hand-drawn, loose style.
- `clean`: Corporate, geometric style.
- `dark`: Optimized for dark mode interfaces.

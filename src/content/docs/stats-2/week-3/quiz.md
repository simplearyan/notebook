# Week 3 Practice Quiz

## Question 1
For a continuous random variable $X$, what is $P(X = c)$ for any constant $c$?

- [ ] 0
- [ ] 1
- [ ] Depends on $f(c)$
- [ ] Undefined

<details>
<summary>View Answer</summary>
**Answer**: 0
**Explanation**: The probability of a continuous random variable taking on any single specific value is always 0.
</details>

# Welcome to Kinetix Docs

Kinetix turns your text into professional motion graphics, charts, and diagrams.

## Features

- **Text to Diagram**: Instantly generate flowcharts and sequences.
- **Export options**: Support for transparent MP4/WebM.
- **Styles**: Switch between professional and hand-drawn aesthetics.

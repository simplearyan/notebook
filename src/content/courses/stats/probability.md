# Probability Basics

Probability is the branch of mathematics concerning numerical descriptions of how likely an event is to occur.

## Key Concepts

1. **Experiments**: Any procedure that can be infinitely repeated and has a well-defined set of possible outcomes.
2. **Sample Space**: The set of all possible outcomes of an experiment.
3. **Events**: A set of outcomes of an experiment.

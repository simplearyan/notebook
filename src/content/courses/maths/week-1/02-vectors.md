# L1.1: Vectors

Vectors are the fundamental building blocks of linear algebra.

## Definition

A vector is an object that has both magnitude and direction.

## Vector Addition

If $\mathbf{u} = (u_1, u_2)$ and $\mathbf{v} = (v_1, v_2)$, then $\mathbf{u} + \mathbf{v} = (u_1 + v_1, u_2 + v_2)$.
